# Anmelden

Melde dich einmal über die CLI an: Führe **Kiro Studio: Bei Kiro anmelden** aus. Ein Terminal öffnet sich und startet
`kiro-cli login`. Schließe die Anmeldung im Browser ab; danach prüft Kiro Studio erneut.

Kiro Studio sieht deine Zugangsdaten nie. Die CLI bewahrt sie auf und nutzt sie selbst.
