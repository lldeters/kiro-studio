# Verbindung prüfen

Führe **Kiro Studio: Einrichtung prüfen** aus. Kiro Studio prüft, dass

- die CLI gefunden wird und läuft,
- du angemeldet bist und
- die CLI die V3-Engine anbietet (wenn nicht, führe `kiro-cli update` aus).

Die Ansicht **Kiro Studio** in der Aktivitätsleiste zeigt das Ergebnis. Das Element in der Statusleiste unten öffnet ein
Menü mit den nützlichsten Aktionen.
